# 武藤游戏｜《杀戮尖塔 2》角色模组

把怪兽召唤、融合与局外卡池构筑带进爬塔。

「武藤游戏」是一款《杀戮尖塔 2》自定义角色模组，包含 **119 张角色相关卡牌**，涵盖主牌、额外怪兽、生成牌与特殊形态。让怪兽留场承担伤害、发动效果，再将它们作为素材进行融合；也可以在开局前规划奖励候选池，围绕自己想玩的组合开始冒险。

本仓库提供可安装的模组包和使用说明，无需自行编译或安装开发用 SDK。

## 下载与安装

**[下载 v0.1.0 完整模组包 · Yugi-Mod-v0.1.0.zip](https://github.com/shamumumu/ThermalVortex-Mod/releases/download/v0.1.0/Yugi-Mod-v0.1.0.zip)**

[查看最新发布版本](https://github.com/shamumumu/ThermalVortex-Mod/releases/latest)

请下载上面的 `Yugi-Mod-v0.1.0.zip`。GitHub 自动生成的 `Source code` 压缩包只包含本仓库的说明文件，不是可玩模组。

需要已安装的《杀戮尖塔 2》。压缩包已附带 **BaseLib 3.1.2**，包含以下内容：

```text
mods/
├─ ThermalVortex/    # 角色模组：DLL、JSON、PCK
└─ BaseLib/          # 必需基础库：DLL、JSON、PCK
安装说明.txt
THIRD_PARTY_NOTICES.md
licenses/LICENSE-BaseLib.txt
```

1. **先退出游戏。** 在 Steam 中右键《杀戮尖塔 2》，通过“管理 → 浏览本地文件”打开游戏根目录。
2. 解压下载的 ZIP，将其中的 `mods` 文件夹合并到游戏根目录。最终应为 `游戏根目录/mods/ThermalVortex/ThermalVortex.dll`，不要放成 `mods/mods/ThermalVortex`。
3. 确认 `BaseLib` 只保留一份。已有 BaseLib 时，检查其他目录或创意工坊中是否存在重复副本；本包提供的配套版本为 3.1.2，不要直接覆盖其他模组所需的新版 BaseLib。
4. 启动游戏，按游戏提示启用模组，选择“武藤游戏”开始新局。

升级模组时也请先退出游戏。角色的显示名称为“武藤游戏”，文件夹和内部标识仍使用 `ThermalVortex`。

## 怪兽也能站上战场

怪兽拥有独立生命，召唤后留在怪兽场中。初始场地有 **3 个怪兽位**，部分卡牌可以扩展容量。面对敌人攻击，通常先消耗玩家格挡，再由场上怪兽从右向左承担伤害。

留场防守、作为素材、主动回收与触发离场效果，都可能成为构筑的一部分。怪兽的位置、剩余生命与素材价值，会影响这一回合该怎么出牌。

## 融合与额外牌组

模组包含 **17 张额外怪兽**。已获得的额外怪兽保存在独立的额外牌组中，每场战斗开始时重新准备；满足条件后，通过融合等卡牌召唤到场上。

不同融合方式可以使用场上、手牌、弃牌堆或消耗堆中的素材，也可以提前消耗抽牌堆素材，在下回合召唤。素材数量、身份与离场效果，共同决定一次融合的收益。

## 可以尝试的玩法

| 体系或卡牌 | 玩法特色 |
|---|---|
| 电子体系 | 场上没有电子龙时，电子龙可以零费打出；电子终结龙随素材数量成长；电子龙无限通过吞噬其他怪兽积累生命与可继承能力。 |
| 千年体系 | 手牌中的千年卡、场上的千年怪兽与千年能力共同形成“千年计数”，围绕抽牌、控牌、能量和融合建立循环。 |
| 五种封印部件 | 尝试在手牌中同时集齐五种封印部件，直接赢得战斗；部件自身也能参与千年体系的运转。 |
| 混沌幻影 | 选择弃牌堆中的怪兽作为当前形态使用，借用其属性与效果，为回收和复制构筑提供变化。 |
| 拉之翼神龙 | 从球形体、不死鸟到翼神龙逐步转换，围绕特殊复活条件与敌人本场累计攻击量展开攻防。 |

## 开局前规划，冒险中成形

除了标准奖励池，还可以预先构筑本局的**奖励候选池**，再通过局内随机奖励逐步组成实际牌组。候选范围包含武藤游戏与原版五位角色的合法奖励牌，可以尝试跨角色组合。

- **自由构筑**：选择 70–90 种主卡目录与 10 种额外目录，保存自己的预设。
- **Genesis**：在 **240 分共同预算**内，为核心牌、支援牌与额外怪兽分配积分。
- **单人三选一**：通过选包与补选完成本局候选池。
- **多人共享选卡**：为 2–4 名均选择武藤游戏的玩家提供共同选卡流程。

这里构筑的是“可能获得哪些奖励”，**起始实际牌组仍为 11 张**。预设支持保存、复制、重命名，以及按来源、稀有度和类型筛选。119 张角色相关卡牌中包含生成专用牌等内容，并非全部进入普通奖励。
