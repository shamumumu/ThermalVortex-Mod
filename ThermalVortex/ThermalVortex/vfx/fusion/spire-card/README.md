# 融合素材的尖塔卡图与卡框

素材卡去掉全部文字与能量图标／数值，包括卡名、卡效文字和中间牌匾的类型文字。空白标题条、稀有度颜色、立绘装饰边框、空白类型牌匾、原生卡框、阴影和背景均保留。卡图位于卡片上半部，下半部保留原生效果说明面板并留空。融合末尾的完整结果卡由宿主另用原生 `NCard` 绘制，不经过本工厂；捕获失败时才用这里的无字卡面回退。

三个卡框、三个对应立绘边框、标题条与类型牌匾在运行时读取玩家游戏的原生 UI 资源，不在模组中分发副本。Atlas 图层在内存中裁出并保留透明边距；原始资源路径与裁剪矩形见 `source-manifest.json`。

`art_frame.gdshader` 保留原框的实际透明轮廓、外沿压边、纹理与下半部效果说明面板，仅在原上部透明立绘窗口合成实际素材图。卡图保持比例适配，按攻击／技能／能力原框的透明窗口形状显示；下半部使用原 PNG 的说明面板，不铺卡图，不绘制效果文字。主卡池框色使用原生 `hsv.gdshader` 的 YIQ 数学；额外卡框直接移植项目 `ExtraDeckCardMaterials.ColdWhiteShaderCode` 的冷白映射与默认参数。无色卡可传入自身卡池参数。

标题条、立绘装饰边框与类型牌匾使用同一个原生稀有度材质，Shader 在运行时读取游戏的 `res://shaders/hsv.gdshader`。稀有度 HSV 由快照提供；缺少参数时按原生 common／uncommon／rare 等材质默认值恢复。工厂不创建任何文字节点，也不加载字体资源。

`../spire_card_faces.gd` 在 340×450 的独立透明 SubViewport 内渲染上述组合：所有原生相对坐标共用中心 `(170,226)`，原框矩形为 `(20,15,300,422)`；整体向上留出四像素，使原生阴影也完整落在画布内，保留外部透明边距。同卡图、框型和着色参数复用一个纹理；每张独特卡面仅 `UPDATE_ONCE`，再次配置时清理旧视口。30 张完全不同卡面合计约 18 MiB 的 RGBA8 颜色数据，实际显存另有引擎开销；重复卡只占一份卡面纹理。

快照字典使用 `portrait`、`type`、`frame_h`、`frame_s`、`frame_v`、`extra_deck`、`rarity`、`banner_h`、`banner_s`、`banner_v`。缓存键包含所有这些视觉参数，卡框或稀有度不同不会误用同一纹理。兼容输入中的 `type_label` 等文字字段会被忽略，不参与绘制或缓存。传入旧的 Texture2D 仍可作为卡图使用；完全缺少快照时使用原生外形内的紫色菱形卡背。此处是按原 UI 图层重组的演出视觉快照，不运行原生 `NCard`，不保存 `CardModel`、规则或费用。
