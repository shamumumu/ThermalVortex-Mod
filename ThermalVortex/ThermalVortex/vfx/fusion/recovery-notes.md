# 融合召唤视觉资源：恢复范围

生产与独立预览共用 `fusion_summon.tscn`、同一组 Godot shader 和同一份时间曲线。场景没有游戏规则、音频、输入拦截或随机数状态。`seek` 可以直接确定每一帧的状态。

## 来自原导出物的内容

- `textures` 中 10 张 PNG 为原文件逐字复制，包含 EfFusion009/010/011/012、MaterialUzu01、渐变和圆角遮罩，以及原卡背。来源与 SHA-256 在 `source-data/source-manifest.json`。没有复制原默认怪兽 `3972Low`；实际素材与预览结果由调用方提供。原卡背保留作来源资料，当前演出改用无文字的原生卡框轮廓替代面，不改变真实素材数量。
- `source-data/curves.json` 保留原 Unity `.anim` 的关键帧、切线、权重与原数字属性，45 个原 clip 来自 InCard、ShowUnitCard、Out、PostFusion。对素材属性 CRC32 的低 28 位匹配原动画绑定，得到 `_Rotate/_TwistStrength/_Scale`、颜色和偏移等候选映射。完整数字来源仍然保留。
- 主扭曲移植 01～05 shader 中的共同 UV 运算：中心缩放；按半径乘 TwistStrength 旋转；减去 Rotate 弧度；按不同素材数使用各自的采样位置。原 1.45 倍卡面比例现适配为 450/340，与当前原生卡框画布一致；透明边界采用合成卡面的自身 alpha。五素材保留原 2.75 倍采样与 -0.875 的中心偏移。
- 两素材直接使用 `summonfusionincard/Recorded` 的原浮点曲线，普通曲线以 Hermite 原切线求值；加权曲线以时间轴上的三次 Bezier 求值。debug 输出使用的源 clip、局部时间及三个核心属性，便于本次预览定点核对。
- 五素材采用 `Recorded (4)`；Num 采用 `Recorded (9)`～`(14)` 的六组原曲线和 `_CardAOffset` 收缩。ShowUnitCard 小旋涡采用原 `_offset/_Amplitude` 曲线、MaterialUzu 与旋转渐变遮罩。

## 明确补建与推定的内容

原包没有保留可完整恢复的 PlayableDirector 对象绑定、粒子发射器/Renderer 组件、原宿主编排与音频数据。当前文件不能证明 01/03/04 的全部 clip 归属。因此这些变体沿用已恢复的两素材运动节奏，分别使用原 1/3/4 槽位 UV 布局；五素材/Num 的 clip 配置同样是基于保存属性的恢复选择，不冒充原绑定完整重放。

红/红B/蓝/蓝B 四层使用原透明纹理与原 1.2 秒窗口；角速度、叠层、余光、震荡环和少量火星是在缺失原发射器时补建的确定性效果。没有加入白色粒子幕或补造缺失音频。原像素、Shader Graph 编辑图、渲染管线与曝光参数并未完整恢复，因此不声称像素级一致。

素材卡展示使用透明 SubViewport 和双面卡片网格。`spire_card_faces.gd` 将调用方的实际卡图与攻击／技能／能力三种原生框合成 340×450 的透明画布，沿用卡池颜色与额外牌组冷白框。卡图只在上半部原生透明立绘窗口内等比显示；下半部保留原 PNG 的效果说明面板并留空，不用卡图覆盖。素材卡不绘制任何文字或能量图标；空白标题条、立绘装饰边、空白中间牌匾、阴影均采用原生资源和相对坐标，前三个装饰层共用实际卡牌的稀有度标题条颜色。工厂不生成 Label，也不依赖字体；兼容快照中传来的类型文字不会显示。相同卡图、框样式与稀有度共享一次绘制的纹理，重新配置时释放。原生 PNG 来源另记录在 `spire-card` 中，与 Unity 融合来源贴图区分。

结果卡由生产宿主的 `FusionResultCardCapture` 使用实际召唤卡牌实例创建原生 `NCard`，按 `PileType.None`、`CardPreviewMode.Normal` 绘制完整卡名、费用、类型和卡效。680×900 透明视口与卡片网格比例一致，取景包含费用图标；等待原生文本布局及绘制完成后冻结纹理。`configure` 的 `result_full_texture` 直接供结果网格采样，不经过无字素材卡工厂；未提供时兼容既有 `result_card` 回退。捕获仅存活于本次演出，结束或退出后归还卡牌节点并释放视口，不写入素材预约。

合成卡面是没有 mipmap 的 ViewportTexture，网格与扭曲采样使用 `filter_linear`。新配置先等待卡面完成一次绘制，再启用卡片／扭曲视口，避免首帧消费尚未绘完的纹理；静态拖动同样刷新。延后刷新带有配置编号和节点状态检查，重新配置、停止或退出后不能唤醒旧展示。

前导翻牌、镜头、屏幕布局及原单位到屏幕尺寸的映射由本场景补建。Num 的多个单卡材质提供扩展依据，超过五张建立每张真实素材对应的独立网格与扭曲节点；超过六张重复曲线组，6～12 张沿环形展开，超过 12 张改用居中多行排列。20 张为 5×4、30 张为 6×5，不满的末行也居中，完整保留顺序与重复素材。扩大 Num 采样坐标时同步补偿中心偏移，避免大数量卡片偏到角落。卡片与扭曲分别绘制到最大宽度 1600 的透明视口，播放结束停用绘制。无额外张数截断，但性能仍随素材数量增长，不能将可配置数量解释为任意数量性能保证。

## 时间与接入约定

本场景的源时间轴选定 ShowUnitCard 前导 80/60 秒，然后主段 182/60 秒，总长 262/60 秒。这是缺失宿主串联信息后的显式接法；不声称原游戏完整演出总长已被证明。主段中的 InCard、Vortex、Out、PostFusion 是重叠子段，不相加：InCard 约 0～1.3333 秒，Num 为 0.0167～2.0167 秒；Vortex 0～1.2 秒；Out 0～2.4667 秒；PostFusion 1.1667～3.0333 秒。StrongSummon 在源主段约 1.8 秒，StartCard 在源主段 2.8167 秒。生产适配器保留既有怪兽 cutin；没有专属登场时在融合末尾显示完整结果卡。

播放节奏按用户指定调整为最初速度的 80%：生产 `FusionSummonVfx` 与独立预览的正常速率均为源时间轴的 0.8 倍，实际时长约 5.4583 秒（前导约 1.6667 秒、主段约 3.7917 秒）；快速模式源速为 1.6 倍，即正常模式的两倍，实际时长约 2.7292 秒。即时模式仍由宿主跳过新增融合段。该调整只改变调用 `play` 时的速率，保留上述源曲线、关键帧切线、`get_duration` 和 `seek` 秒数。预览状态栏明确标注源时间。原有怪兽专属登场的播放速度保持不变。

`configure` 必须在加入树且 `_ready` 完成后调用。`play` 从头开始；`seek` 不发完成信号；`set_paused(false)` 可从暂停位置继续；自然到结尾仅发一次 `finished`；`stop` 重置并隐藏，不发完成事件。所有动态效果只依赖当前取样时间，不依赖播放历史。

生产快照只保存每张素材的卡图路径、框类型、类型文字、稀有度、卡框／标题条颜色标量和额外牌组标记，不保存卡名、费用、效果、纹理或卡牌实体。预约复制时独立复制有序数组；缺少旧预约快照仍按实际素材数配置替代面。融合／融合+、电子负载融合、奇迹融合、融合之门、千年融合及其复制效果由统一即时入口播放，未来融合由下回合的统一预约入口播放，保留各来源的支付与素材数量规则。

宿主必须先将场景加入 CanvasLayer 和 SceneTree，再调用 `SetAnchorsAndOffsetsPreset(FullRect)`。不能在挂载前为这个已带 FullRect 锚点的根节点设置视口 `Size`，否则宽高会同时变成额外偏移，挂载后演出尺寸翻倍、中心落到屏幕右下角。2026-09-12 已用独立 Godot 按实际 C# 挂载顺序复现：1600×900 视口得到 3200×1800 的错误演出区域；修正后区域与视口一致，卡片和旋涡居中。此前工作台采用挂载后 FullRect，未覆盖这条宿主路径。

来源提取脚本位于仓库 `ThermalVortex/design/fusion-summon-preview/prepare-source-assets.py`，需要 Python 和 PyYAML。提取器只读取指定的融合资源子目录，按清单复制 PNG 并核对 SHA-256；生产运行与普通预览不需要原始导出目录或 Python。
